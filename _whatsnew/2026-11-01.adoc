=== Throughput decision points

You can now see client throughput recommendation and automation decision points. Hover over a decision point to view details, such as the current and recommended SKU or  breached metrics in time window (%).

link:https://docs.netapp.com/us-en/workload-eda/task-use-overview-dashboard.html#analyze-capacity-trends-and-decision-points[Learn about decision points^].

=== Re-run latency analysis

You can now select *Run analysis again* to launch a new latency analysis for a volume and refresh the results on demand.

link:https://docs.netapp.com/us-en/workload-eda/task-analyze-latency-issues.html[Learn about analyzing latency issues^].

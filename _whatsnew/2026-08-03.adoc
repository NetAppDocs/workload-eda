=== Elastic throughput increase management

You can now manage throughput increase behavior from the EDA Overview page for one or more selected FSx for ONTAP file systems.

* *Mode selection*: Choose *Automate* or *Recommend*.
* *Bulk updates*: Select one or multiple file systems and apply mode and parameter changes in one action.
* *Change throughput management dialog*: Edit throughput increase settings with EDA default values in the dialog.
* *Advanced settings*: Configure additional throughput decision parameters in an expandable *Advanced configuration* section.
* *Table visibility*: A new *Throughput management* column is available in the Clusters table and can be enabled from column settings.
* *Top card configuration*: The upper card now supports throughput increase mode configuration, similar to SSD management.

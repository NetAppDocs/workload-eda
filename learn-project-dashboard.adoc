= Learn about the Projects dashboard in Workload Factory for EDA
:icons: font
:imagesdir: ./media/

[.lead]
The Projects dashboard lets IT admins and project managers see how projects use storage across FSx for ONTAP file systems and volumes. It shows storage usage patterns so you can spot projects using the most resources, track costs, and adjust storage before capacity or performance problems affect EDA simulations.

== How the Projects dashboard works

The Projects dashboard shows CloudWatch metrics for all FSx for ONTAP volumes linked to your AWS credentials. You can create up to five filters using AWS tags to organize and view the data by project, team, application, or other categories.

The dashboard helps you:

* Plan capacity and understand costs  
* Use data to decide how to assign resources  
* Spot projects that use a lot of resources  
* Track costs by project or team  
* Adjust storage before problems occur

For proactive latency performance monitoring, see link:learn-latency-monitoring.html[Learn about latency monitoring].

=== CloudWatch metrics collected

The dashboard collects and displays the following CloudWatch metrics:

* *Provisioned capacity*: Volume-level metric representing the provisioned storage capacity.
* *Used capacity*: Volume-level metric representing the storage used.
* *Average/Maximum throughput*: Calculated as the average or maximum of the sum of DataReadBytes and DataWriteBytes over the specified time period.
* *Average/Maximum IOPS*: Calculated as the average or maximum of the sum of DataReadOperations, DataWriteOperations, and MetadataOperations over the specified time period.

== Custom filters

Custom filters help you organize dashboard data to match how your organization works. Set filters by project, team, or cost center so you can quickly find the data you need without sorting through unrelated information. This makes it easier to plan capacity, track costs, and monitor performance.

You can configure up to five custom filters based on your AWS tags.

* *Filter label name*: The display name that appears in the dashboard
* *AWS tag key name*: The actual AWS tag key used on your resources
* *Selection type*: Single selection or multi-selection

If you don't configure any custom filters, the default filters—file system, volume type, and time range—will still be available, so you can view and use your dashboards.

=== AWS tags

AWS tags are metadata for your AWS resources. They help you categorize your AWS resources in different ways, for example, by project, application, or business unit. 

To use custom filters, add AWS tags to your FSx for ONTAP volumes that match your needs, such as tags for projects, teams, or business units.

For more details about tagging, see https://docs.aws.amazon.com/whitepapers/latest/tagging-best-practices/what-are-tags.html[What are tags?^] and https://docs.aws.amazon.com/resourcegroupstagging/latest/APIReference/overview.html[AWS Resource Groups Tagging API Reference^].

== Volume details

The dashboard provides viewing modes to help you analyze your storage metrics at different levels of detail.

=== Total view

The Total view (default) shows combined metrics for all volumes that match your selected filters. It gives you a quick overview of overall storage performance, including total capacity, IOPS, and throughput. 

Use this view to:

* Understand overall trends
* Plan for future capacity needs
* Report on total resource consumption across projects or teams

=== Volume view

The Volume view shows how individual volumes perform over time. It displays the top 10 volumes for each metric. This helps you see which volumes use the most resources and how they behave during the selected time period.

Use this view to:

* Find what is slowing performance  
- Identify storage volumes that might need to be resized  
- See which projects or workloads are using the most resources

==== Volume metrics displayed

When you view individual volumes, the dashboard displays the top 10 volumes out of your total number of volumes for each metric:

* *Volume used capacity*: Shows volumes with the highest current used capacity.
* *IOPS*: Shows volumes with the highest average IOPS during the selected time period.
* *Throughput*: Shows volumes with the highest average throughput during the selected time period.

NOTE: The dashboard displays only the top 10 volumes for each metric. If you have more than 10 volumes, some volumes might not be displayed in the detailed view.

When the same volumes appear in multiple metrics, the dashboard uses the same colors in the legend so you can easily follow those volumes across different metrics.

==== Interactive volume data

Hover over the chart to see exact values at specific times. This helps you link performance changes to events or time periods. The detailed data can help you find performance problems, confirm that optimizations worked, and explain resource usage to others.

When you hover over any volume line in the graphs, you can view:

* *Volume used capacity*: Volume name, used capacity at that point in time, and allocated capacity
* *IOPS*: Volume name, average IOPS for the time range, and maximum IOPS for the time range
* *Throughput*: Volume name, average throughput for the time range, and maximum throughput for the time range

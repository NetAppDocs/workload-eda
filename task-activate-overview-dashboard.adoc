= Activate the Overview dashboard in Workload Factory for EDA
:icons: font
:imagesdir: ./media/

[.lead]
Activate the Overview dashboard to start collecting CloudWatch metrics for your FSx for ONTAP file systems. The dashboard lets you see cluster health, capacity, and throughput in one place.

== Before you begin

Ensure you meet the following requirements before activating the dashboard.

=== AWS credentials with view permissions

You must configure AWS credentials in Workload Factory with at least read (view) permissions for General Storage. _Basic_ credentials are not supported because they don't include the necessary read permissions for CloudWatch metrics.

If you haven't configured credentials with view permissions, you are redirected to the AWS credentials setup page when you open the Overview tab.

If you haven't configured AWS credentials, see link:https://docs.netapp.com/us-en/workload-setup-admin/add-credentials.html[Add AWS credentials^].

== Activate the dashboard

After Workload Factory verifies credentials with view permissions, activate the dashboard to start collecting CloudWatch metrics for your FSx for ONTAP file systems.

NOTE: After you give consent, collecting metrics can take a little time. The dashboard will notify you while the first collection is in progress.

.Steps

. Log in using one of the link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html[console experiences^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon] and then select *EDA*.
. Select the *Overview* tab.
. If no credentials with view permissions are detected, select *Add credentials* and follow the prompts to configure AWS credentials with view permissions. Then return to the *Overview* tab.
. Review the consent prompt describing the CloudWatch metrics that will be collected for your FSx for ONTAP file systems.
. Select *Activate* to activate the dashboard and begin metrics collection.

.Result

Workload Factory starts collecting CloudWatch metrics for all FSx for ONTAP file systems linked to your AWS credentials. The dashboard populates as the metrics become available. A notification appears while data collection is still in progress.

== Next steps

After activating the dashboard, you can:

* link:task-use-overview-dashboard.html[Use the Overview dashboard] to monitor cluster health and capacity
* Enable and configure SSD capacity management modes (Recommend, Automate, or None)
* Enable and configure throughput management modes (Recommend, Automate, or None)
* Set up filters to focus on specific regions or AWS accounts

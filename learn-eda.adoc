= Learn about Workload Factory for EDA
:icons: font
:imagesdir: ./media/

[.lead]

Workload Factory for EDA helps you optimize FSx for ONTAP across multiple file systems. You can optimize for performance and reduce operational costs by automating storage parameters, analyzing performance constraints, and get insights on EDA projects. 

It is designed to integrate with your Infrastructure as Code (IaC) frameworks.

Workload Factory for EDA provides dashboards and storage automation frameworks and utilities that help you manage multiple FSx for ONTAP file systems. 

It offers the following: 

* link:task-use-overview-dashboard.html[Overview dashboard]: provides a centralized cluster view to help you monitor FSx for ONTAP cluster health, capacity, and throughput, determine where to place new volumes, make informed decisions about scaling capacity and throughput, and receive automated capacity recommendations or enable automated capacity scaling. View historical decision points to understand algorithm behavior over time.
* link:task-monitor-latency.html[Monitor volume latency]: proactively monitors volume read and write latency performance with configurable warning and critical event thresholds. Receive email or SNS notifications when events are detected. Includes automated basic analysis using ONTAP QoS delay center metrics and optional AI-agent analysis for complex scenarios requiring deeper root cause identification.
* link:task-analyze-latency-trends.html[Analyze latency trends]: use the interactive latency graph to visualize latency behavior over time, identify patterns, understand whether performance issues are recurring or isolated, and make data-driven decisions about remediation.
* link:task-configure-dashboard.html[Projects dashboard]: provides a centralized view of storage consumption across your FSx for ONTAP file systems to help you plan, assess costs, and collect information on storage usage across your projects.
* link:learn-eda-workloads.html[CI/CD]: streamlines and reduces software build time by leveraging FSx for ONTAP volume clone capabilities.
